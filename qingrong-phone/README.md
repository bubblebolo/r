# 清融的手机 · 使用说明

一个仿 iPhone 界面的互动小站。所有内容（照片、微博、微信、地图、聊天、备忘录……）都由 `data.js` 控制。

---

## 一、怎么打开看效果

**不要直接双击 `index.html`。** 浏览器对本地 `file://` 读取图片有安全限制，会白屏。

在这个文件夹里开一个本地服务器：

```bash
# 方式一：Python（Mac/Linux 自带）
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000

# 方式二：Node
npx serve .
```

**解锁密码：`1029`**

## 三、文件结构

```
qingrong/
├── index.html      ← 页面外壳（基本不用改）
├── data.js         ← ★ 你的所有内容都在这里
├── app.js          ← 交互逻辑（不用改）
├── i18n.js         ← 界面文案字典（想改按钮文字再动）
├── wallpaper.jpg   ← 锁屏壁纸
├── photos/         ← 相册 + 微博配图 + 聊天图片
└── media/          ← 头像、封面
```

**核心原则：只改 `data.js`，再往 `photos/` 和 `media/` 里放图。**

## 四、★ 改成你自己的名字（最常改的地方）

打开 `data.js`，**最上面第 1 节**：

```js
const PEOPLE = {
  '人物一': { avatar: 'media/p1.jpg', note: '' },
  '人物二': { avatar: 'media/p2.jpg', note: '', unread: 2 },
  '人物三': { avatar: 'media/p3.jpg', note: '' },
  '人物四': { avatar: 'media/p4.jpg', note: '' },
  '人物五': { avatar: 'media/p5.jpg', note: '' },
  '人物六': { avatar: 'media/p6.jpg', note: '' }
};
```

**改法：把冒号左边的 `'人物一'` 换成真名即可，别动右边的结构。**

```js
'陈可': { avatar: 'media/p1.jpg', note: '' },
```

- 键名（单引号里那个）就是**所有地方显示的名字**：微信列表、通讯录、聊天页、电话记录、锁屏通知，全部自动跟着变，不用改第二处。
- `avatar`：这个人的头像，换成 `media/` 里你自己的图片。
- `unread`：可选，微信列表右上角的未读数。
- 想加减人数：直接增删这一节的行。**但要注意 `chatData`（第 9 节）里的键名必须对得上**，否则那条聊天记录找不到人。

> 另外 `data.js` 第 9 节的 `chatData` 用的也是同一批名字做 key。如果改了名，把那里的 key 一起改掉。

### 主角和其他常量

```js
const OWNER = '清融';        // 手机主人
const OWNER_INITIAL = '清';  // 通讯录头像里的那个字
const CITY = '杭州';         // 天气显示的城市
```

## 五、密码和生日

在 `data.js` 最后：

```js
const PIN_CODE = '1029';     // 4 位数字，改成你要的
const BIRTHDAY = 'today';    // 'today' = 永远显示今天
```

`BIRTHDAY` 有三种写法：

| 写法 | 效果 |
|---|---|
| `'today'` | 每次都显示打开当天的日期 + 「今天」 |
| `{ month: 10, day: 31 }` | 显示 `10月31日 · 还有 N 天`，到当天自动变成「今天」 |
| `null` | 不显示生日 |

锁屏底部那张便签和备忘录里都读这个值，改一处两边都变。

## 七、微博

在 `data.js` 找到 `WEIBO` 和 `WEIBO_POSTS`：

```js
const WEIBO = {
  name: '清融',                  // 昵称
  avatar: 'media/ig_avatar.jpg',
  verified: '微博个人认证',       // 黄 V 后面的文字
  following: 231, fans: '1.2万', posts: 86
};

const WEIBO_POSTS = [
  // [昵称, 认证文案, 头像, 时间, 正文, 配图数组, 转发, 评论, 点赞]
  ['清融','微博个人认证','media/ig_avatar.jpg','今天 14:26',
   '今天天气好得不像话 #随手拍# #杭州#',
   ['ig_01.jpg','ig_02.jpg','ig_03.jpg'], 128, 46, 1024]
];
```

- **配图**：留 `[]` 就是纯文字微博；1 张显示大图；2~9 张自动变九宫格。
- **话题**：正文里写 `#随手拍#` 会自动变成橙色话题链接。
- **图片路径**：只写文件名，程序会自动去 `photos/` 里找。

### ★ 发视频

配图数组里直接写 `.mp4` 文件名就行，程序会自动认出它是视频：

```js
const WEIBO_POSTS = [
  ['JDG清融v', '微博个人认证', 'media/ig_avatar.jpg', '今天 14:26',
   '学习了一下holymoly 还行吗',
   ['ig_01.mp4'], 128, 46, 1024]
];
```

- 卡片里直接显示视频（首帧做封面），中间一个播放按钮，左下角标「视频」
- **点一下播放，再点一下暂停**；同时只会有一个视频在播，点第二个会自动停掉第一个
- 支持 `mp4` / `mov` / `webm` / `m4v`
- **可以图文混排**，比如九宫格里一格视频两格图片：

```js
['ig_05.jpg', 'clip.mp4', 'ig_06.jpg']
```

- 文件放 `photos/` 里；写 `media/xxx.mp4` 也能识别
- 视频不用写 `thumb`，第一帧就是封面

> ⚠️ **编码必须用 H.264**。浏览器（尤其 iPhone Safari）播不了 HEVC / H.265，
> 遇到「点了没反应」，先确认编码。转码命令：
>
> ```bash
> ffmpeg -i 原视频.mov -c:v libx264 -pix_fmt yuv420p -movflags +faststart 输出.mp4
> ```
>
> 手机拍的 `.mov` 基本都是 HEVC，一定要转这一下。

界面结构：顶部「关注 / 推荐」双 tab，底部五栏（首页 / 视频 / 发现 / 消息 / 我），点「我」进个人主页。

## 八、微信

微信列表就是 `chatData` 里所有人，顺序按 `PEOPLE` 的先后。

四个底部 tab：**微信 / 通讯录 / 发现 / 我**。

### 聊天记录 ★ 最重要的部分

```js
const chatData = {
  '人物一': [
    ['10月16日', 'date'],          // 日期分隔线
    ['在吗', 'me'],                // 'me'   = 你发的（右侧绿色气泡）
    ['在的', 'them'],              // 'them' = 对方发的（左侧白色气泡）
    ['今天下班有空吗', 'me'],
    ['有啊 怎么了', 'them', '9:42'] // 第三项可选，手写时间
  ]
};
```

**发图片 / 语音 / 文件**：先登记，再引用。

```js
const CHAT_IMAGES = {
  '[照片1]': 'photos/chat_01.jpg'
};

// 聊天里这样写
['[照片1]', 'me']
```

同理还有 `CHAT_AUDIO`（语音）和 `CHAT_FILES`（文件卡片）。

> 群聊在这一版是**关闭**的：`window.GROUP_PATTERN = /$^/;`（永不匹配）。
> 想重新打开，把 `data.js` 里那行改成 `/群|组|通知|公告/`，并在 `GROUP_MEMBERS` 里配置成员。

### 为什么聊天页打不了字

这一版故意把聊天页做成了**只读**，底部显示「这段对话只能看，不能回复」。因为自动回复动画已按你的要求关掉，留着输入框反而会出问题。想打开见下一节。

## 九、动画开关（想恢复自动互动就改这里）

`data.js` 第 9.5 节：

```js
const AUTO_CHAT = false;         // ← 总开关
const LIVE_PARTNER = '人物一';   // ← 自动互动挂在谁身上
```

| `AUTO_CHAT` | 效果 |
|---|---|
| `false`（当前） | 聊天页只读，不会自动打字、不会自动弹消息、不会自动来电 |
| `true` | 打开 40 秒后对方主动发消息、会替你打草稿、会在指定时间打来电话 |

打开后还需要配这几个：

```js
const liveReplies = [            // 你发一句，对方怎么回
  { mine: ['下班一起吃个饭？'], them: ['好呀', '你定地方'] }
];
const INCOMING = ['在干嘛呢', '刚路过你说的那家店'];   // 主动发来的消息
const speech = [[LIVE_PARTNER,'喂'], [OWNER,'嗯 怎么啦']]; // 通话台词
const PHONE_AFTER = [[LIVE_PARTNER,'又打过来啦']];      // 挂断后补发
```

`CALL_ASK_AT`（240 秒）和 `CALL_AT`（390 秒）控制什么时候问「方不方便打电话」和什么时候真的打来。演示想快点看到，把数字改小。

> **注意**：`AUTO_CHAT = false` 只关掉这一类自动演出。锁屏上滑、密码键盘、图标缩放、页面推拉、微博和微信内部的手势动画**都没有动**。

## 十三、几个提醒

- **图片版权**：占位图是生成的色块，你自己的照片随便用。别把别人的照片、明星图放上去公开发布。
- **数据都在前端**：所有内容写死在 `data.js` 里，打开浏览器源码就能看到。不要写真实的隐私信息（地址、电话、真名）。
- **改完没生效**：浏览器缓存。强制刷新（Ctrl/Cmd + Shift + R）。
- **中文乱码**：确认编辑器保存为 UTF-8 编码。
- **白屏**：99% 是没开本地服务器（见第一节），或者 `data.js` 里少了个逗号。按 F12 看 Console 的红色报错。
- **生日卡片显示成方块**：如果那个位置出现方框，是电脑缺 emoji 字体（比如 🎂）。这版已经去掉了 emoji，只留纯文字，正常不会出现。
